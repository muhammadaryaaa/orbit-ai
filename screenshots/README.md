# Screenshots

Capture screenshots from the **actual running app** (not mockups) at a consistent viewport, e.g. 1440×900, after signing in / loading demo data.

Required shots:
1. `dashboard.png` — Dashboard, productivity overview
2. `ai-chat.png` — AI Chat, a real conversation with ORBIT AI
3. `task-manager.png` — Task Manager, tasks and priorities
4. `ai-task-breakdown.png` — AI Task Breakdown modal with generated subtasks
5. `planner.png` — Planner, daily or weekly schedule
6. `insights.png` — Insights, productivity analytics
7. `settings.png` — Settings, preferences and memory

How to capture:
```bash
npm run dev   # http://localhost:3000
```
Open each route, use realistic demo data, capture with your OS screenshot tool or browser DevTools (Cmd/Ctrl+Shift+P → "Capture screenshot"), and save the file here with the names above.
